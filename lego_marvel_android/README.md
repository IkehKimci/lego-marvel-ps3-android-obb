# LEGO Marvel Super Heroes (BLUS-31161) — Native Android ARM64 Port (`ps3recomp`)

Native Android ARM64 static-recompilation port of **LEGO® Marvel Super Heroes (USA / `BLUS31161`, SDK 04.4600)** built on [`ps3recomp`](../ps3recomp).

## Architecture

Upstream `ps3recomp` targets Windows/Linux/macOS with SDL2. This tree adds a native Android ARM64 (`aarch64-linux-android`) backend with zero SDL2 or X11 dependencies:

## Directory Layout

- `CMakeLists.txt` — Builds shared PIC object library `lego_marvel_core`, `adrenotools` + hook `.so`s (`libhook_impl.so`, `libmain_hook.so`, `libfile_redirect_hook.so`, `libgsl_alloc_hook.so`), `libps3recomp_lego_marvel.so` (APK), and `lego_marvel_cli` (shell runner).
- `relay_server/` — Free Multi-Room Online Co-op Relay Server implementations:
  - `relay_server/node/server.js` (+ `package.json`, `Dockerfile`, `render.yaml`) — Zero-dependency pure Node.js server supporting **both** WebSocket (`wss://`, 100% free on Render.com Singapore / Koyeb / Railway) and Multi-Port Raw TCP (`TCP_PORTS=31161-31170` on VPS/PC/Termux), SHA-256 room password isolation (`403`/`404`/`409` protection), and a live HTML/JSON status dashboard.
  - `relay_server/cloudflare/worker.js` (+ `wrangler.toml`) — Free-tier Cloudflare Workers + Durable Objects WebSocket Hibernation API relay (Jakarta/Singapore edge `< 20 ms`).
- `android/java/com/ps3recomp/legomarvel/LauncherActivity.java` — Native Android Launcher UI: OBB status check, **Co-op 2 HP Online (Server Relay / Multi-Room)** card (Mode `Server Online (Relay)` vs `LAN`, Server Address, Port / Room Number `1–65535`, Password Room, Host screen mode `Off`/`Auto Split`/`Force Split`/`Full Mirror`, `Balanced 78%`/`Fill 100%`/`Fit` aspect, Stream Bitrate `1.5 Mbps`/`800 Kbps`/`3.5 Mbps`, Audio toggle, **⚡ Tes Server / Cari LAN**, and zero-OBB **"📱 GABUNG PLAYER 2 (HP 2)"** button), Custom Vulkan Driver Manager, graphics/scaling (FSR/SGSR/CAS/Integer/Bilinear)/Frame Gen/Low-End settings, physical gamepad detector, and built-in log viewer.
- `android/java/com/ps3recomp/legomarvel/CoopRelayLink.java` — Zero-dependency pure-Java RFC 6455 TLS WebSocket (`wss://`/`ws://` with SNI) & Raw TCP (`tcp://` with 44-byte `LMRL` handshake) relay transport with SHA-256 room password authentication, thread-safe `LMV1` framing, and `testServerHealth()` latency check.
- `android/java/com/ps3recomp/legomarvel/GameActivity.java` — Fullscreen `NativeActivity` running in isolated `android:process=":game"`, non-intercepting `TYPE_APPLICATION_PANEL` HUD overlay (real-time FPS, `×2 FG`, `PAD`, Online Relay room status / LAN Host IP), `CoopStreamServer` lifecycle, and clean Back-button shutdown.
- `android/java/com/ps3recomp/legomarvel/CoopStreamServer.java` — Phone 1 Co-op Host streamer supporting Online Relay (outbound single-connection H.264 video + 24 kHz Stereo IMA-ADPCM audio OUT, `PKT_INPUT` → `cellPad` Port 1 IN, auto-reconnect) and LAN Direct (`TCP :31161`, `UDP :31160` discovery, cellular `rmnet*` filter, `MulticastLock`), logging diagnostics to `logs/coop_host.log`.
- `android/java/com/ps3recomp/legomarvel/CoopClientActivity.java` — Standalone Phone 2 Co-op client (**zero OBB required**, runs in main process without loading native `.so`): supports Online Relay (`Room Port + Password`) and LAN Direct, hardware H.264 `SurfaceView` decoder (+ JPEG fallback), 24 kHz Stereo IMA-ADPCM `AudioTrack` player (tap top status pill for 1-tap 🔊/🔇 mute), DualShock 3 multi-touch + physical USB/BT gamepad input (square outer-gate projection & Nintendo swap), and live error/FPS status pill.
- `src/android_main.cpp` — `ANativeActivity_onCreate`, `settings.ini` loader, OBB-only zero-copy mount & boot-metadata staging, writable `PS3_GAMEDATA_ROOT` + `PS3RECOMP_SPIRV_CACHE` + `chdir()` setup, `coop_udp_input_thread` (LAN `UDP :31162`), JNI HUD & Co-op exports (`nativeGetFrameStats`, `nativeGetFrameGenStats`, `nativeGetGamepadState`, `nativeGetRenderHeight`, `nativeGetVirtualPadState`, `nativeCoopSetClientConnected`, `nativeCoopSetMode`, `nativeCoopGetStatus`, `nativeCoopFillYuvPlanes`, `nativeCoopFillRgba`, `nativeCoopPushP2Input`, `nativeCoopSetAudioEnabled`, `nativeCoopReadAudioAdpcm`), custom Vulkan loader, 60 Hz RSX `frame_clock`, 2-player `AInputQueue` gamepad + touch combiner, 4 GB guest VM runner, auto-logger, and crash handler.
- `src/stubs.cpp` — Title-specific HLE NID bridges (`_cellGcmFunc15`, `cellSpursDestroyTaskset2`, `cellSpursJoinTask2`, `cellSpursGetJobChainInfo`, `cellSaveDataGetListItem` → real HLE, `cellSail` v1/adapter helpers, `sysPrxForUser`) + `lego_music_list_lock`/`unlock` recursive mutex protecting BLUS-31161 global music list (`0x01CC04E8`) against multi-thread drain/insert/search races and NULL-link hangs across `ppu_recomp_{026,042,043,044}.cpp`.
- `src/port_extension.cpp` — Sets default Android runtime flags (`PS3RECOMP_VK_GUEST_PROGRAMS=1`, `PS3RECOMP_VK_DIRECT_PRESENT=1`, `PS3RECOMP_RSX_SINGLE_PRESENT=1`, `VK_DRAW_BATCH=1`, `VK_DRAW_BATCH_MAX=4096`, `PS3RECOMP_VK_ASYNC_PIPE=1`, `PS3RECOMP_FP_HALF=1`, `PS3RECOMP_ENG_FEEDBACK_PER_PASS=1`, `PS3RECOMP_GCM_FLIP_PACING=adaptive`, `PS3RECOMP_GCM_PPU_PUT_KICK=1`, `PS3RECOMP_GCM_SPU_PUT_KICK=1`, `SPU_FLOAT_RZ=1`, `SPU_INTERP_UNLIFTED=1`, `PS3RECOMP_SPU_INTERP_FALLBACK=1`, `PS3_VERBOSE=0`).
- `scripts/extract_iso.py` — Pure-Python ISO9660 extractor for `BLUS-31161` metadata or full `PS3_GAME/` (`GAME*.DAT`, ~8.35 GB).
- `scripts/pack_obb.py` — Pure-Python uncompressed ZIP64 (`ZIP_STORED`) OBB packager & verifier for packaging `PS3_GAME/` into `main.2.com.ps3recomp.legomarvel.obb`.
- `scripts/lift_and_build.sh` — Full Stage 1–6 pipeline (`ppu_loader` + `find_functions` → `ppu_lifter --code-end --chunks 128 --jobs 1` → `gen_hle_nids` → `build_spu_workloads --allow-partial` → CMake/Ninja → signed APK).
- `scripts/package_apk.sh` — Compiles Java (`javac --release 11` + `d8 --min-api 26` → `classes.dex`) & resources (`aapt2`), bundles ARM64 `.so`s (`libps3recomp_lego_marvel.so`, `libc++_shared.so`, `libglslang.so`, `libSPIRV.so`, `libglslang-default-resource-limits.so`, and AdrenoTools hooks), `zipalign`s, and signs with `apksigner` (v2/v3).
