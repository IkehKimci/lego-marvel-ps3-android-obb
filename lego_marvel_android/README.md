# LEGO Marvel Super Heroes (BLUS-31161) — Native Android ARM64 Port (`ps3recomp`)

Native Android ARM64 static-recompilation port of **LEGO® Marvel Super Heroes (USA / `BLUS31161`, SDK 04.4600)** built on [`ps3recomp`](../ps3recomp).

## Architecture

Upstream `ps3recomp` targets Windows/Linux/macOS with SDL2. This tree adds a native Android ARM64 (`aarch64-linux-android`) backend with zero SDL2 or X11 dependencies:

## Directory Layout

- `CMakeLists.txt` — Builds shared PIC object library `lego_marvel_core`, `adrenotools` + hook `.so`s (`libhook_impl.so`, `libmain_hook.so`, `libfile_redirect_hook.so`, `libgsl_alloc_hook.so`), `libps3recomp_lego_marvel.so` (APK), and `lego_marvel_cli` (shell runner).
- `android/java/com/ps3recomp/legomarvel/LauncherActivity.java` — Native Android Launcher UI: status check (loose `PS3_GAME/` or `.obb`), Custom Vulkan Driver Manager (auto-imports AdrenoTools/Turnip `.zip` packages from `/storage/emulated/0/Download/`, manual `.zip` picker, delete, Adreno Turbo Mode), graphics settings (`480p`/`540p`/`720p`/`1080p`, `60 FPS (Unlocked)`/`30 FPS`/`Uncapped`, **Lossless Scaling** `FSR1+RCAS`/`CAS`/`Integer`/`Bilinear`, Guest Shaders, Direct Present, real-time FPS HUD toggle), SPU/FMV/Touch/Verbose toggles, and built-in `latest.log` / `crash_last.log` viewer.
- `android/java/com.ps3recomp/legomarvel/GameActivity.java` — Fullscreen `NativeActivity` running in isolated `android:process=":game"` (clean 4 GB guest VM & fresh Vulkan driver on every launch), non-intercepting `TYPE_APPLICATION_PANEL` HUD overlay (real-time JNI FPS, frame-time `ms`, & resolution pill + animated DualShock 3 virtual gamepad with moving Left/Right analog thumbknobs and pressed-button highlights), and clean Back-button process shutdown without ANR.
- `src/android_main.cpp` — `ANativeActivity_onCreate`, `settings.ini` loader (`resolution`, `fps_limit` → `PS3RECOMP_GCM_FLIP_PERIOD_US` + `0x015B369C` 60 FPS unlock, `scaling_mode` → `PS3RECOMP_VK_SCALING`), loose-folder + zero-copy Android `.obb` auto-mount & boot-metadata staging, writable `PS3_GAMEDATA_ROOT` + `PS3RECOMP_SPIRV_CACHE` + `chdir()` setup, JNI HUD & virtual-pad state exports (`nativeGetFrameStats`, `nativeGetRenderHeight`, `nativeGetVirtualPadState`), `ps3_android_open_custom_vulkan()` (`libadrenotools` + `dladdr` hook-dir resolution), nanosecond 60 Hz RSX `frame_clock`, Vulkan surface lifecycle, `AInputQueue` gamepad + complete DualShock 3 multi-touch mapper with square outer-gate analog stick response, 4 GB guest VM runner, automatic shared-storage logger, and async-signal-safe crash handler (`sigaltstack` + AArch64 registers + guest fault EA + `_Unwind_Backtrace`).
- `src/stubs.cpp` — Title-specific HLE NID bridges (`_cellGcmFunc15`, `cellSpursDestroyTaskset2`, `cellSpursJoinTask2`, `cellSpursGetJobChainInfo`, `cellSaveDataGetListItem` → real HLE, `cellSail` v1/adapter helpers, `sysPrxForUser`).
- `src/port_extension.cpp` — Sets default Android runtime flags (`PS3RECOMP_VK_GUEST_PROGRAMS=1`, `PS3RECOMP_VK_DIRECT_PRESENT=1`, `PS3RECOMP_RSX_SINGLE_PRESENT=1`, `VK_DRAW_BATCH=1`, `VK_DRAW_BATCH_MAX=4096`, `PS3RECOMP_ENG_FEEDBACK_PER_PASS=1`, `PS3RECOMP_GCM_FLIP_PACING=adaptive`, `PS3RECOMP_GCM_PPU_PUT_KICK=1`, `PS3RECOMP_GCM_SPU_PUT_KICK=1`, `SPU_FLOAT_RZ=1`, `SPU_INTERP_UNLIFTED=1`, `PS3RECOMP_SPU_INTERP_FALLBACK=1`, `PS3_VERBOSE=0`).
- `scripts/extract_iso.py` — Pure-Python ISO9660 extractor for `BLUS-31161` metadata or full `PS3_GAME/` (`GAME*.DAT`, ~8.35 GB).
- `scripts/pack_obb.py` — Pure-Python uncompressed ZIP64 (`ZIP_STORED`) OBB packager & verifier for packaging `PS3_GAME/` into `main.2.com.ps3recomp.legomarvel.obb`.
- `scripts/lift_and_build.sh` — Full Stage 1–6 pipeline (`ppu_loader` + `find_functions` → `ppu_lifter --code-end --chunks 128 --jobs 1` → `gen_hle_nids` → `build_spu_workloads --allow-partial` → CMake/Ninja → signed APK).
- `scripts/package_apk.sh` — Compiles Java (`javac --release 11` + `d8 --min-api 26` → `classes.dex`) & resources (`aapt2`), bundles ARM64 `.so`s (`libps3recomp_lego_marvel.so`, `libc++_shared.so`, `libglslang.so`, `libSPIRV.so`, `libglslang-default-resource-limits.so`, and AdrenoTools hooks), `zipalign`s, and signs with `apksigner` (v2/v3).

## Settings, Saves, Custom Drivers, Logs & Crash Reports

- `/storage/emulated/0/PS3/BLUS31161/gamedata/dev_hdd0/home/00000001/savedata/` — Persistent PS3 save slots (`BLES00000000/`, `PARAM.SFO`, `ICON0.PNG`, save payloads).
- `/storage/emulated/0/PS3/BLUS31161/gamedata/trophies/` — Persistent trophy progress (`NPWR04400.json`).
- `/storage/emulated/0/PS3/BLUS31161/gamedata/vk_pipeline_cache.bin` — Persistent Vulkan GPU shader/pipeline ISA cache (auto-saved asynchronously & reused across launches).
- `<app_internal_files>/spirv_cache/` — Fast internal-storage disk cache of `glslang` HLSL→SPIR-V translations (`PS3RECOMP_SPIRV_CACHE`).
- `/storage/emulated/0/PS3/BLUS31161/settings.ini` — Launcher configuration (`resolution`, `fps_limit`, `scaling_mode`, `guest_shaders`, `direct_present`, `show_fps`, `spu_interp_fallback`, `skip_fmv`, `verbose_log`, `touch_controls`, `adreno_turbo`, `driver_mode`, `driver_name`, `driver_dir`, `driver_lib`).
- `/storage/emulated/0/PS3/BLUS31161/logs/latest.log` — Live log of the current session (rate-limited & flushed continuously).
- `/storage/emulated/0/PS3/BLUS31161/logs/prev.log` — Previous session's log (preserved across restarts).
- `/storage/emulated/0/PS3/BLUS31161/logs/crash_last.log` — Fatal signal crash report (`SIGSEGV`/`SIGABRT`/`SIGBUS`/`SIGILL`/`SIGFPE`/`SIGTRAP`) with fault address, guest EA offset, AArch64 registers, and unwound symbol backtrace.

If shared storage permission is not yet granted, saves/trophies and logs automatically fall back to `/storage/emulated/0/Android/data/com.ps3recomp.legomarvel/files/` (and internal app storage). All output is also mirrored to `logcat -s ps3recomp`.

## Build Output & Game Data

- **Signed native APK:** `dist/lego-marvel-ps3-arm64.apk` (also copied to `/storage/emulated/0/Download/lego-marvel-ps3-arm64.apk`).
- **Game data (Android OBB — required for APK, no automatic loose-folder fallback):** `/storage/emulated/0/Android/obb/com.ps3recomp.legomarvel/main.2.com.ps3recomp.legomarvel.obb` (zero-copy ZIP64 mount; also checked in `/storage/emulated/0/Download/` or `/storage/emulated/0/PS3/BLUS31161/`).
- **CLI runner (`lego_marvel_cli`):** Accepts either a `.obb` archive or a loose `EBOOT.ELF` path explicitly via `argv[1]`.
- **Lifted coverage:** 43,569 PPU functions across 129 C++ translation units, 225/225 imported NIDs covered, 8 natively lifted SPU programs (including MultiStream audio mixer & 4 Edge/decompression SPURS jobs) + SPU interpreter fallback for any remaining SPURS jobs/tasks.
